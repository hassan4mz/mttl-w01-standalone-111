배포/Docker image에는 FWR을 포함하지 않습니다. 선택 펌웨어 준비/검증 시 1.0.105를 직접 다운로드해 로컬 생성하며, 다운로드가 안 되면 사용자가 확보한 exact 1.0.105 또는 LG U+ 1.0.66 FWR을 /data/firmware-source/에 넣고 다시 준비하세요. 자동 OTA는 하지 않습니다. 1.0.111은 TCP/49217 우선→TCP/80 fallback, 1.0.66/1.0.110은 TCP/80을 사용합니다.

고급 MQTT 항목

Power/Energy는 선택한 주기마다 변화량을 확인해 기준 이상일 때만 전송합니다. Power 기본값은 0.1W / 30초, Energy는 1Wh / 1분입니다. 전압/RSSI도 활성화한 센서만 전송됩니다.

MTTL-UP Lovelace 카드

채널 이름과 HA Entity Registry를 사용하며, entity_id를 직접 바꿔도 unique_id 기준으로 다시 찾습니다.

mttl-up-card.js 다운로드

type: custom:mttl-up-card
mac: 001122334455
all_control: true

카드는 기본적으로 UI 제어가 잠긴 상태로 열리며, Online 왼쪽의 방패를 해제한 동안에만 Outlet/ALL 제어가 동작합니다. 물리 Child Lock이 켜진 Outlet/ALL에만 자물쇠가 상태 표시되며, Child Lock 제어는 카드에서 하지 않습니다. 카드 편집 UI에서 ALL 제어 표시를 끌 수 있습니다. Home Assistant의 /config/www/mttl-up-card.js에 저장하고 대시보드 리소스에 /local/mttl-up-card.js를 JavaScript Module로 등록합니다.
