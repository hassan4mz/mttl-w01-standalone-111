Custom FWR
Only files validated for model/header/checksum/version/SHA can be registered.

Releases/Docker images do not include FWR files. When preparing the selected firmware, 1.0.105 is downloaded and generated locally; if the download fails, place an exact 1.0.105 or LG U+ 1.0.66 FWR you obtained into /data/firmware-source/ and prepare again. No automatic OTA is performed. 1.0.111 prefers TCP/49217 with a TCP/80 fallback; 1.0.66/1.0.110 use TCP/80.

Home Assistant MQTT

Advanced MQTT options

Power/Energy are checked at the selected interval and sent only when the change meets the threshold. Defaults: power 0.1 W / 30 s, energy 1 Wh / 1 min. Voltage/RSSI are sent only for enabled sensors.

MTTL-UP Lovelace card

Uses channel names and the HA entity registry; entities are re-found by unique_id even if you rename entity_id directly.

Download mttl-up-card.js

type: custom:mttl-up-card
mac: 001122334455
all_control: true

The card opens with UI controls locked by default; Outlet/ALL control works only while the shield left of Online is unlocked. Padlocks appear only on outlets/ALL with physical Child Lock enabled; Child Lock control is not offered in the card. You can hide the ALL control in the card editor. Save it to /config/www/mttl-up-card.js in Home Assistant and register /local/mttl-up-card.js as a JavaScript Module dashboard resource.

Admin password

There is no separate username. The new password must be at least 8 characters.
